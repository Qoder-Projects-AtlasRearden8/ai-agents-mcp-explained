01

Agents are loops

A language model chooses a step, a harness checks it, tools act, and the result comes back. Capability comes from the whole system, not the model alone.

Start with the idea →
02

MCP is a plug

The Model Context Protocol gives AI apps a common way to discover and call tools. It makes integrations portable. It does not make them safe.

Understand the protocol →
03

Safety is design

Prompts shape behavior; permissions, drafts, approvals, and logs enforce boundaries. Start small, review the trace, and widen access only with evidence.

Read the safety chapter →

Who it is for

Curious beginners. Careful practitioners. The person everyone asks when the computer misbehaves.

The manual assumes no coding experience. It also gives developers and managers a shared vocabulary for the questions that matter: what can this agent see, what can it do, when does a human decide, and how do we know it worked?
